1应用概览

悦泽健康 YozerHealth 是一款完全离线运行的本机健康档案应用，无需注册登录、无账号、无云端。

📷
拍照 / 相册 / PDF 识别

端侧 OCR 自动读取报告单数值，自动比对参考区间并标记异常；自动判别检验 / CT / B超等报告类型。

🎙️
语音口述录入

说一句「血压 138 88」，自动拆成结构化指标。

🧬
疾病与用药时间线

记录起病与康复时间，未康复自动标记「持续治疗中」。

📈
趋势与一键汇总

单指标折线趋势、异常集中呈现，一键生成就诊摘要给医生看。

🗂️
分类 / 检索 / 归档

按生命体征、检验、影像等五大类归档，支持全局搜索。

🔒
加密与应用锁

敏感字段 AES 加密落盘；支持 PIN 码与指纹 / 面容解锁。

隐私承诺：应用已在系统层面移除联网权限，OCR 模型内置手机本地，图片、文字与音频不会上传任何服务器。

「结构化档案」区的疾病、用药记录统一在健康摘要（医生视图）里查看和管理时间线。

4拍照 / PDF 智能识别（核心功能）

识别在你的手机上本地完成，整个过程分四步：

📷 拍照 / 选图 / PDF
→
端侧 OCR 识别文字
→
自动判型 + 解析
→
人工核对 → 保存
🧪 识别为「检验报告」 自动把白细胞、血红蛋白、转氨酶等指标逐项填充（含数值、单位、参考区间、↑↓异常标记），并自动归类到「检验」大类和对应小类（血常规 / 尿常规 / 肝功能 / 肾功能 / 血脂 / 生化）。
🩻 识别为「CT / B超 / MR / X光 / 心电图」 只保留文字内容：自动提取「检查所见」与「诊断结论」两个段落（影像所见 / 超声提示 / 检查描述等写法都支持），自动归入「影像检查」大类并填好小类，识别到的杂散数字不会混成指标。

复核页能做什么

  • 原图对照：页面显示原图缩略图，点击看大图，逐项核对。
  • 检验时间自动填入：从报告上提取检验 / 检查 / 采样时间（其次报告日期），填入「检验时间」输入框，可手动修改；留空则记为录入时刻。
  • 逐项纠错：每个指标都能改名称、数值、单位、参考上下限，或整条删除；识别漏了可「手动添加一项」。
  • 所见 / 结论可编辑：影像类报告的两个文字段落均可在保存前修改。
  • 增强重识别：对灰暗、倾斜的翻拍件，可再跑一遍对比度增强通道重新识别。
  • 查看识别原文：展开 OCR 原文，方便判断解析是否错位。
提示：OCR 只做辅助，保存前请务必对照原图核对数值。兼容「3.5--9.5」双横线、小数点后带空格（「4. 49」）等常见 OCR 噪声。

记录详情与编辑

  • 详情页展示标题、分类、时间、医院、指标表格（异常项高亮）、所见与结论文字。
  • 详情页可点「📎 源文件」查看原始附件（图片 / PDF）：图片与 PDF 均支持双指捏合缩放，PDF 还可双击在原大 / 2.5 倍间切换，放大后单指拖动平移。
  • 编辑页可修改全部字段并增删指标；删除需确认。
  • 首页「📈 指标趋势」入口可查看体重、血压、血糖、心率、血氧等指标的长期趋势折线图与日历视图。
  • 参考区间标注：趋势图中自动绘制「参考区间上下限」虚线并标注参考值（如血压 90–139 / 60–89），区间外的数据点以红色高亮为异常，一眼看出偏离。

全局搜索

首页点击搜索图标，可按标题 / 内容 / 指标名全局检索，结果中可直接进入详情、编辑或删除。

7健康摘要（医生视图）

就诊时最常用的页面：把重要信息浓缩成一页给医生看。

  • 入口：首页顶部头像旁的入口，或分类页「健康档案」。
  • 内容：成员基础信息、关键异常（近 3 月）、当前用药、诊断治疗史、历史疾病时间线、历史用药时间线、过敏史与手术史（均可在页内录入、编辑、删除）。
  • 展示模式：一键切换为大字号、隐藏编辑入口的「展示模式」，方便直接把手机递给医生看。
  • 分享摘要：底部「📤 分享摘要」可一键导出为多页 PDF——三个标签页内容各占一页、合并为一份文档（生成失败会自动退回纯文本），也可直接分享纯文本，通过微信 / 邮件等发给医生或家人。
摘要末页注明「仅供就诊参考，不作为诊断依据」。

8家庭成员管理

  • 支持添加多位家庭成员（姓名、性别、出生年、身高、体重），各自的数据完全独立。
  • 首页头像栏点击即可切换成员；「我的」页可编辑 / 删除成员资料。
  • 删除成员会同时删除其全部健康数据，请谨慎操作（建议先导出备份）。

9数据与隐私安全

隐私设计

  • 无账号、无云端：不需要注册登录，所有数据只存在你的手机里。
  • 识别全程离线：OCR 模型内置于应用，图片与文本不上传服务器。
  • 语音不录音：调用系统语音识别，应用不保存音频。
  • 字段级加密：敏感字段经 Keystore 托管密钥 AES-256-GCM 加密后落盘。
  • 已移除联网权限：系统层面无法发起任何网络连接。

应用锁

  • 「我的」页可开启 PIN 码锁（仅存加盐哈希，无法还原）与指纹 / 面容解锁。
  • 开启后每次进入应用需先解锁；支持修改 PIN，关闭锁需验证旧 PIN。

数据管理（我的 → 数据管理）

  • 本机数据概览：查看记录数、附件占用等。
  • 导出健康摘要（文件）：生成文本摘要文件，走系统分享面板发送。
  • 导出全部数据（文件）：纯文本形式的完整数据导出，便于查看。
  • 导出备份包（全部成员）：把全部成员的数据库信息、药品 / 报告图片、PDF 原件等整体打包成一个 zip 文件，走系统分享面板发出；换手机后可通过「导入备份包」整体恢复。
  • 导出当前成员备份包：仅打包当前选中成员的数据，适合只想迁移某一位成员的情景。
  • 导入备份包：在「我的 → 数据管理」选择备份 zip，整体恢复数据（含图片 / PDF 原件）：
    • 全部成员备份：先清空本机全部数据再恢复（完整迁移，覆盖）。
    • 单成员备份：仅替换该成员的数据，不影响其他成员（合并）。
    • 备份以明文写入 zip，导入时由目标设备用其自身密钥重新加密入库，因此备份包可在任意设备安装同版本应用后恢复（换手机是典型场景）。
  • 清空健康数据：不可恢复 删除当前成员的全部记录、指标、疾病、用药与档案（含附件副本），基础资料保留。操作需二次确认，请先导出备份。
卸载应用或清除应用数据将彻底删除所有内容，重要数据请定期导出备份。

10常见问题

Q：识别不到指标怎么办？

①点「增强重识别」对灰暗 / 倾斜照片再试一次；②展开「识别原文」手动对照；③用「手动添加一项」补录；④照片尽量平整、光线充足、占满画面。

Q：报告上的日期会自动记进去吗？

会。识别后自动提取「检验 / 检查 / 采样时间」（没有则退化为报告日期）填入「检验时间」框，你可手动修正；留空则记为录入时刻。

Q：CT / B超这类没有数值的报告怎么录？

直接拍照或导 PDF，应用会自动识别为影像类报告，只保留「检查所见」「诊断结论」文字段落，不会把报告里的尺寸数字误存为指标。

Q：卡片上的「📎 源文件」是什么？

是这条记录对应的原始照片 / PDF。点击角标即可直接预览附件，不必先进详情页。

Q：换手机数据怎么办？

在「我的 → 数据管理」点「🗜 导出备份包（全部成员）」，把打包好的 zip 通过微信 / 网盘等发到新手机；在新手机上打开同版本应用，进入「数据管理 → 📥 导入备份包」选择该 zip 即可整体恢复（含图片与 PDF 原件）。单成员也能单独导出 / 导入。
