悦泽健康 YozerHealth · 应用介绍

【一】一句话定位
------------------------------------------------------------
把散落在纸质单、相册和各家医院 App 里的健康记录，收进一部手机；
看得到趋势，讲得清病史，数据一步不出手机。

【二】应用简介
------------------------------------------------------------
化验单、CT 报告、血压血糖记录散落各处？拍照或导入 PDF，端侧 OCR
自动提取指标与参考区间，一眼看出异常；趋势图带参考上下限，就诊时
一键生成医生视图与 PDF 摘要。无账号、无联网、无云端，敏感数据加密
留在本机。

【三】详细介绍
------------------------------------------------------------
体检报告塞在抽屉里，化验单躺在相册深处，去年那次 CT 写了什么再也
翻不到。到了诊室，医生问「之前指标怎么样」，只能凭印象答个大概。

悦泽健康把这些记录收进一部手机里，也只留在这部手机里。

拍一下，报告就变成了能查、能比的数据
  拍照、选相册图、导入 PDF，手机本地 OCR 自动判断报告类型：化验单
  逐项填入数值、单位、参考区间并标出偏高偏低；CT、B 超、MR 这类
  影像报告只提取「检查所见」和「诊断结论」，不会把尺寸数字误当成
  指标。保存前可对照原图逐项核对、改错、补录，照片不清楚还能增强
  重识别。原件永久留档，随时点开看大图、缩放翻页。

不想打字也能记
  除拍照与 PDF，还有模板录入、随手文字、语音口述（说一句「血压
  138 88」自动拆成结构化指标）、疾病与用药时间线，共 8 种入口。
  血压、血糖、体重、心率、血氧自动归入五大类档案，全局搜索一搜
  就到。

指标不再是孤立的一串数字
  血压趋势同时画收缩压与舒张压两条线，每条线都有正常参考上下限
  虚线、每个采样点的数值，落在区间外的点直接标红；血氧、体重、
  心率同理。分析页用本机规则给出概览、关键发现、可执行的复查
  建议，还能看出哪些体检项目从没记过。

就诊时，把手机递过去就够了
  「医生视图」一页汇总近 3 月关键异常、当前用药、疾病与用药时间线、
  过敏史和手术史；切成大字号展示模式，或导出成多页 PDF 提前发给
  医生。摘要末页明确标注「仅供就诊参考，不作为诊断依据」。

一家人的档案互不干扰
  支持多位家庭成员独立建档、一键切换；换手机时用备份包整体迁移，
  图片与 PDF 原件一起带走，导入后恢复如初。

隐私不是选项，是地基
  无需注册登录、没有账号、没有云端；应用已在系统层面移除联网权限，
  OCR 模型内置手机，语音不保存音频；敏感字段经 Keystore 托管的
  AES-256-GCM 加密落盘，再加 PIN 码与指纹 / 面容应用锁。你的健康
  数据，只有你和医生能看到。

适合谁
  需要长期监测血压血糖的慢病人群；每年体检、跨院就诊的人；帮父母
  整理报告、陪诊的家属；不愿把病历交给任何云服务的任何人。


【四】功能模块
------------------------------------------------------------
1. 拍照识别    拍照 / 相册 / PDF 端侧识别，检验指标与影像结论自动分离
2. 趋势可读    血压双线趋势 + 参考区间 + 逐点数值，异常一眼可见
3. 就医视图    一页汇总病史、用药与近 3 月异常，支持大字号展示与 PDF 导出
4. 录入省心    8 种录入方式，语音口述自动结构化，长辈也会用
5. 全家共用    多成员独立档案，备份包换机完整迁移
6. 隐私优先    全离线无账号，加密存储 + PIN / 生物识别应用锁


【五】亮点
------------------------------------------------------------
A. 报告不丢，病史说得清，数据不出手机。
B. 一部手机，装下一家人的健康档案。
C. 拍下报告，剩下的交给本机。
D. 给医生看的那一页，早就准备好了。
